# Stage 1 Concept and Feasibility Report

This folder contains the November 20, 2026 Stage 1 report for the Remote Environmental Survey project.

- `feasibility-report.tex` is the editable LaTeX source. It uses the IEEEtran conference class in one-column format so the evidence and requirements tables remain legible.
- `feasibility-report.pdf` is the compiled four-page copy for review and printing.

The report follows the assignment's six required sections. It recommends proceeding with conditions and distinguishes tested subsystems, user-reported results, simulations, and open hardware checks. All repository `src/` code is proof-of-concept work. The complete rover-to-watch survey, measured physical acceptance tests, final custom PCB, and integrated clean-copy build remain open.

To rebuild, run `pdflatex feasibility-report.tex` twice from this folder with IEEEtran installed. Review the resulting PDF before submission, especially the concept scores, risk estimates, evidence status, and black-and-white print legibility.
